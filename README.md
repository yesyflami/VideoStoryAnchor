# VideoStoryAnchor

**把剧本变成「首帧 + 尾帧 + 文字描述」的可执行分镜表，让图生视频模型产出可控、连续的镜头。**

一个给 AI 视频创作者的技能（Skill）。适用于 Claude Code / DeepSeek Harness 等支持 Skill 的 Agent 环境。

---

## 它解决什么问题

用图生视频做片子，最常见的失控不是模型不够强，而是**你只给了它一张图**。

一张图意味着：运镜方式、动作幅度、结束状态，全都由模型猜。于是你会看到——

- 想让它慢慢推近，它自己推过头
- 想让它走过来，它原地晃
- 想让它最后停住，它一直动到最后一帧
- 同一个角色，换个机位就变成另一个人
- 上一镜朝右飞，下一镜朝左飞

**首尾帧把两端钉住，中间的插值就被约束了。**

这个技能做的就是把剧本拆到镜头级，为每个镜头写清"从什么状态到什么状态"，并在出图之后做连续性检查。

---

## 五步工作流

```
剧本 / 剧情描述
      │
 ① 拆镜 ──→ 镜头表（时间码、画面、镜头、声音、台词、产线）
      │
 ② 定锚 ──→ 每镜写两句话：首帧状态 / 尾帧状态（只写状态，不写过程）
      │
 ③ 出图 ──→ 首尾帧各一张；同角色只出一次母图，其它机位从母图编辑
      │
 ④ 检锚 ──→ 方向 / 身份 / 留白 / 道具 / 光线　五条硬检查
      │
 ⑤ 生成 ──→ 首尾帧喂给图生视频；实测验收，不信模型自述
```

**关键在第 ② 步。** 一个镜头的锚写不出来，说明这个镜头的动作你还没想清楚——回第 ① 步，不要带着模糊的锚去生图。

## 安装

把整个目录放到你的 Agent skills 目录下：

```bash
# 常见位置
~/.agents/skills/VideoStoryAnchor/      # DeepSeek Harness
~/.claude/skills/VideoStoryAnchor/      # Claude Code
```

Windows:

```
C:\Users\<you>\.agents\skills\VideoStoryAnchor\
```

确认 `SKILL.md` 在目录根部即可，无需构建。

---

## 快速开始

在 Agent 里直接说：

> 用 VideoStoryAnchor 把这段剧本拆成分镜表

或者更具体：

> 帮我把这三段剧情做成首尾帧方案，标清方向、留白和产线

它会产出：

- 一张镜头表（每镜的时间码、画面、镜头语言、声音、台词、产线标签）
- 每个镜头的**首帧 / 尾帧**文字锚
- 每镜的生成提示词（静帧 + 图生视频）
- 一份连续性检查结果

## 四类镜头，四套做法

| 类型 | 产线 | 核心要点 |
|---|---|---|
| **空镜** | 静帧 → 图生视频 | 真的没人；动点写死；时长够用就好 |
| **口播** | 近景 → 对口型模型 | 正脸、嘴部无遮挡、面部占 35%、眼睛睁开 |
| **转场** | 首尾帧 → 图生视频 | 动作结束后的**方向**必须写清 |
| **文字** | 代码渲染（HyperFrames / Remotion） | 永远不交给生成模型 |

---

## 七条硬纪律

这些是踩过才知道的，写进技能里避免重复踩：

1. **方向连续是第一个被破坏、最难被发现的错误。** 做一次镜像，全片相关镜头一起镜像。
2. **空镜就真的没人。** 要有人就在表里写明他在做什么、朝哪、占画幅多少。
3. **说话和不说话必须分镜。** 空镜里嘴闭着，台词只在近景发生。
4. **文字、标板、Logo 永远不用生成模型。** 中文字形尤其不可靠。
5. **模型烧进画面的字幕只能裁，不能修。** 裁底部条带补回画幅；局部修补会留竖条纹。
6. **电平逐段实测归一。** 不同素材能差 6 dB 以上，统一增益会一条爆音一条仍轻。
7. **同一角色不要分别在两个镜头里"生成"两次。** 那一定是两个人。

## 两条来自真实事故的提醒

**口型对不准，先查音频，别急着重跑模型。**

一条 2.57 秒的配音，语音实际只占 0.50–1.26 秒（29%），其余全是静音。模型没有可对的目标，结果给出"没声音时嘴张得最大、说话时反而抿着嘴"。裁掉前后静音、尾部留 0.6 秒给模型闭嘴，问题消失。

**转场镜头的方向必须在锚里写死。**

一个主体从左往右飞、撞进右侧光门，尾帧却被写成"从左侧飞出"——剪起来像主体凭空回到起点。写转场锚时，先在心里放一遍运动轨迹，确认它是连续的。

## 什么时候不用

- **纯文字 / 排版镜头** → 用代码渲染，不需要这个技能
- **单张插图、海报** → 那是文生图
- **没有对应近景图却要精确口型** → 先按 `references/shot-recipes.md` 口播规格出图

---

## 适用模型

工作流本身与模型无关。已在以下链路上验证：

- **MiniMax H3**（图生视频，支持首尾帧）
- **Kling 数字人**（图 + 音频 → 对口型）
- 其它支持首尾帧的图生视频模型（可灵、Seedance、Vidu 等）同样适用
