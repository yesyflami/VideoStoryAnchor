# 验收清单

**核心纪律：不信模型的自我描述，只信实测。**

一次"看起来成功了"的生成，可能藏着方向翻转、烧入字幕、削波、时长错位四个问题。这些都要量出来。

---

## 一、静帧验收（出完图立刻做）

- [ ] **方向**：跨镜头主体朝向一致（拿分镜表的"方向"列逐条对）
- [ ] **身份**：同角色不同机位，下颌线 / 眉眼距离 / 发际线三处一致
- [ ] **服装道具**：点名要求的物品都在（围裙、杯、包、耳饰）
- [ ] **留白**：文字层要贴的位置是空的、低信息量的
- [ ] **光源**：方向与色温与同场景其它镜头一致
- [ ] **画幅**：16:9，无黑边

不合格就修图。**不要带着已知问题进入视频生成**——视频生成的返工成本是图的十倍。

---

## 二、视频验收

### 1. 抽接触表看动作

```bash
# 每秒 2.4 帧，4x3 拼一张
ffmpeg -y -i clip.mp4 -vf "fps=2.4,scale=470:-1,tile=4x3" \
  -frames:v 1 -update 1 sheet.png
```

看三件事：
- 首帧和尾帧是否落在预期的状态上
- 中间有没有崩坏帧（脸变形、物体穿模、比例突变）
- 方向是否全程一致

### 2. 查画面有没有烧入文字

**部分对口型接口在收到语音时会自动加字幕。** 提示词拦不住，必须查。

```bash
# 单独切出底部条带放大看
ffmpeg -y -ss 1.0 -i clip.mp4 -vf "crop=IW:300:0:IH-300,scale=1000:-1" \
  -frames:v 1 -update 1 bottom_check.png
```

发现书面文字的处理：

| 方法 | 结果 |
|---|---|
| ✅ 裁掉底部条带再补回画幅 | 干净，代价是画面轻微推近 |
| ❌ delogo / 局部修补 | 留竖条纹，比字幕更难看 |
| ❌ 换个提示词重跑 | 同一接口通常照样加 |

裁剪并补回 16:9 的写法：

```bash
# 原片 1904x1072，裁掉底部 252px 保留 820，再补成 1920x1080
-vf "crop=1457:820:223:0,scale=1920:1080"
```

### 3. 查时长与流

```bash
ffprobe -v error -show_entries \
  format=duration -show_entries \
  stream=codec_type,duration,nb_frames,width,height,r_frame_rate \
  -of json clip.mp4
```

常见事故：**视频轨和音频轨长度不一样**。对口型接口返回的音频可能比视频短（例如视频 2.13s、音频只有 1.05s），此时用 `amix duration=first` + `-shortest` 会把画面一起截短。

正确做法是**显式写时长**：

```bash
-map "[v]" -map "[a]" -t 4.14   # 不用 -shortest，用 -t 钉死
```

## 三、声音验收（逐段实测）

### 1. 量原始电平

```bash
ffmpeg -hide_banner -i clip.mp4 -af volumedetect -vn -f null -
```

看输出里的 `mean_volume` 和 `max_volume`。

### 2. 判断要不要加增益

不同配音素材的原始电平能差 6 dB 以上。**不要用统一增益。**

真实的坑：八段台词统一用固定增益，其中一条直接顶到 `0.0 dB`、1037 个采样被削平。

正确做法：

1. 逐段量 `mean_volume`
2. 计算增益：`增益倍数 = 10 ^ ((目标均值 − 实测均值) / 20)`
3. 目标均值取 **−22 dB**（对白）
4. 后面接一个限幅器防溢：`alimiter=limit=0.7:level=false`

```bash
# 例：实测 mean = −25.7 dB，目标 −22 dB
# 增益 = 10^((−22 −(−25.7))/20) = 10^(0.185) ≈ 1.53
[1:a]aresample=44100,volume=1.53,alimiter=limit=0.7:level=false[vo]
```

### 3. 验证没有削波

对话段单独量一次，`max_volume` 应该落在 **−1 ~ −6 dB** 之间。出现 `0.0 dB` 就是削波了，必须重做。

### 4. 验证环境声不断

```bash
ffmpeg -hide_banner -i final.mp4 -af silencedetect=n=-45dB:d=0.08 -vn -f null -
```

如果切点附近出现静音段（例如 `silence_start: 2.000 / silence_end: 2.190`），说明环境声在切点断掉了。

**根源通常是**：把音频也一起 `-t` 截断了，后面靠 `apad` 补的是静音。**只在视频上 trim，音频取完整长度。**

## 四、拼接验收

多段拼成一条之后：

```bash
# 全程每秒一帧的缩略图，7x6
ffmpeg -y -i seq.mp4 -vf "fps=1,scale=300:-1,tile=7x6" \
  -frames:v 1 -update 1 seq_sheet.png
```

逐条检查：
- [ ] 每段的入点是否落在预期时间码
- [ ] 跨段是否出现方向翻转、身份跳变
- [ ] 各段电平是否一致（抽样量 2–3 段）
- [ ] 有没有哪一段带着烧入字幕
- [ ] 总时长与分镜表的和是否一致

---

## 五、最容易漏的三条

1. **只有 0.1 秒的静音也算断**。观众听不出长度，但听得出"断"。
2. **削波听不出来，只量得出来**。凡是看到 `max_volume: 0.0 dB`，一定有失真。
3. **方向错误在单镜头里看不出**。必须把相关镜头放在一起看，或者盯分镜表的"方向"列。
